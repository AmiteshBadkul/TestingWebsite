Project 01

Reducing ERP onboarding abandonment by 30%.

Users were leaving before completing required setup steps. The redesign transformed a dense first-time setup experience into a guided flow with clearer decisions, earlier validation, and better progress visibility.

Outcome 30%

reduction in onboarding abandonment

Primary design goal Clarity

make required ERP setup understandable and recoverable

Core users 3 groups

new ERP users, admin users, and support teams

Drop-off funnel Where users lost confidence
Account created 100%
Role selected 78%
Required data entered 54%
Setup submitted 38%
Key friction themes What needed to change
  • Users did not know how many steps remained.
  • Required fields were explained too late.
  • ERP terminology made role selection harder.
  • Errors appeared after users had already moved forward.
  • Setup tasks were not sequenced around user intent.

Recreated Solution

From one long setup path to a guided enterprise onboarding flow.

I broke the experience into logical steps, grouped related fields, added a persistent progress indicator, clarified enterprise terminology, introduced inline validation, and added a final review step before submission.

Reflection

Enterprise UX is not about hiding complexity. It is about sequencing complexity so users can complete important tasks confidently.

The biggest lesson from this work was balancing simplification with required business rules. By improving structure, accessibility, recovery, and stakeholder alignment, the product experience became easier to adopt without weakening the enterprise process it needed to support.
